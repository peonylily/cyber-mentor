# Cyber Mentor | المرشد السيبراني

منصة تعليمية عربية تجريبية تساعد المتعلم على تحديد موضوع الأمن السيبراني الذي يحتاج إلى تدريب إضافي، باستخدام نموذج تعلم آلة من نوع **Decision Tree**.

## المزايا
- واجهة عربية باتجاه RTL وهوية بصرية مستوحاة من مراكز عمليات الأمن السيبراني (SOC).
- ثلاثة مسارات تعليمية: التصيد الإلكتروني، حماية الخصوصية، كلمات المرور.
- نموذج تصنيف فعلي باستخدام `scikit-learn`.
- تقسيم البيانات إلى تدريب واختبار وعرض Accuracy وPrecision وRecall ومصفوفة الالتباس.
- مجموعة بيانات اصطناعية مرفقة، لا تحتوي على بيانات طلاب حقيقيين.

## تشغيل المشروع على جهازك

1. ثبّت Python 3.10 أو أحدث.
2. افتح الطرفية داخل مجلد المشروع.
3. ثبّت المكتبات:

   ```bash
   pip install -r requirements.txt
   ```

4. شغّل التطبيق:

   ```bash
   streamlit run app.py
   ```

5. سيفتح التطبيق في المتصفح. إذا لم يفتح تلقائيًا، انسخ الرابط المحلي الذي يظهر في الطرفية.

## ملفات المشروع
- `app.py`: واجهة المنصة وصفحاتها.
- `model.py`: تدريب نموذج شجرة القرار وتوقع المسار.
- `train_model.py`: تشغيل التدريب وعرض مقاييس التقييم من الطرفية.
- `data.csv`: بيانات اصطناعية للتدريب والاختبار.
- `requirements.txt`: المكتبات المطلوبة.

## ملاحظة منهجية مهمة
البيانات في `data.csv` **مصطنعة لأغراض بناء النموذج الأولي**، والتصنيف التجريبي مبني على قاعدة تعليمية بسيطة: اقتراح الموضوع ذي الدرجة الأقل. لذلك لا يجوز تقديم نتائج النموذج على أنها قياس حقيقي لمهارات الطلاب أو دليل على فعاليته في بيئة تعليمية حقيقية. يلزم لاحقًا مراجعة المحتوى، وتصميم بيانات تقييم مناسبة بموافقة المدرسة، ثم إعادة التدريب والاختبار قبل استخلاص نتائج بحثية.

## الخصوصية والسلامة
- لا تدخِل أسماء أو أرقام هواتف أو كلمات مرور أو أي معلومات شخصية.
- لا ترفع بيانات سرية إلى أدوات عامة.
- المنصة تعليمية فقط؛ لا تفحص أجهزة أو شبكات ولا تنفذ اختبارات اختراق.
